## Current Phase

Phase 3 — SAP Remote Integration (częściowo). Model CAP domeny działa przez OData V4/H2. Zweryfikowano aktywny binding H01 i autoryzowany runtime `$metadata` oraz `$expand`: 4 nagłówki, 9 pozycji, 6 referencji. Dodano model zdalny CDS, konfigurację CAP Remote Service/Destination i adapter CQN read-only; testy CAP/H2, kontraktu adaptera oraz blokady publicznego dostępu do zdalnego modelu przechodzą. Odczyt LIVE przez CAP **zaliczony** 2026-10-27 (4/9/6, UUID zgodne), lokalnie przez env `destinations`; Destination w BTP dla CF nadal do skonfigurowania. Szczegóły: [CAP-03](journal/2026-10-27-cap-03-sap-remote-integration.md). IAS/XSUAA i KSeF pozostają poza zakresem.

## Architecture

SAPUI5 → OData V4 → CAP Java + Spring Boot → Java SDK KSeF w jednej JVM. SAP przez Remote OData/Destination jest źródłem danych finansowych; CAP przechowuje proces KSeF. H2 lokalnie, SAP HANA Cloud i SAP BTP Cloud Foundry docelowo. Szczegóły: [ADR-0001](decisions/ADR-0001-cap-java-ksef-architecture.md).
